Варіант: 20
Тема Узагальнені типи (Generics). IRepository з where-обмеженнями та тестами.
Мета Навчитися створювати узагальнені інтерфейси та класи, застосовувати where-обмеження для типів-параметрів, а також розробляти юніт-тести за допомогою xUnit для перевірки коректності узагальнених реалізацій.
Хід роботи:
 Створив основний проєкт lab7v20 та тестовий проєкт lab7v20.Tests (xUnit) у папці OOP-Rybonka.
 Підключив посилання на основний проєкт до тестового через dotnet add reference.
 Реалізував інтерфейс IEntity та сутність Event (поля Name, Location, EventDate) за варіантом 20.
 Створив узагальнений інтерфейс IRepository<T> з обмеженням where T : class, IEntity та його реалізацію InMemoryRepository<T> для виконання CRUD-операцій у пам'яті.
 У проєкті lab7v20.Tests написали юніт-тести для перевірки методів Add, GetById, GetAll, Update, Delete та обробки винятків для відсутніх елементів.
 Перевірив роботу програми через dotnet run та успішно пройшов усі тести командою dotnet test.
