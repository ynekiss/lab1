В ході виконання лабораторної роботи No2 було опановано практичні навички створення класів у C# з кількома перевантаженими конструкторами та реалізацією їх ланцюгового виклику за допомогою ключового слова : this(). На прикладі розробленого класу Figure було досліджено життєвий цикл об’єкта, налаштовано валідацію даних у властивостях (зокрема, перевірку площі на від’ємні значення) та протестовано роботу збирача сміття (Garbage Collector) і деструктора (~Figure()) для автоматичного звільнення ресурсів.
